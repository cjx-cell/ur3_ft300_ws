# 文档入口

1. [当前任务与接手指南](PAP_MOE新对话接手指南.md)：唯一当前状态、未完成任务、代码/数据/检查点合同。
2. [运行与资源边界](RUNNING.md)：依赖、采集/转换/训练/推理入口及尚未公开的资源。
3. [来源与项目贡献](CONTRIBUTIONS.md)：上游、修改范围、许可证。
4. [LeRobot组织方案](LEROBOT_INTEGRATION.md)：锁定上游与项目增量；完整剥离暂缓。
5. [实验推进与结论](reports/PAP_MoE推进顺序与实验结论_简版_20260907.md)：历史与最新对比，不混算合同。
6. [当前物理信息验证](reports/PAP_MoE物理条件信息有效性验证_20260909.md)：实验设计；实时结果优先看接手指南和本机status.json。
7. [整理与恢复](CLEANUP.md)、[旧SA-MoE唯一说明](LEGACY_SA_MOE.md)。

`reports/` 保存有证据价值的历史报告；其中“正在训练”等仅指标题日期的状态，不作为今天的启动指令。演示在`assets/`，可机读配对摘要在`results/`。
