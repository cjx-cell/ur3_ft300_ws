# PAP-MoE工程正确性与专项能力验收

## 1. 目标正式澄清

PAP-MoE要在**预先明确的物理交互条件**下优于基线，例如密集接触、视野丢失、安全接触或卡滞后的恢复；不是要求所有情况下均胜出，不是保持Pi0.5动作后加修补，也不是靠开环MSE或动作更像Pi0.5证明有效。

目前普通完整插孔是基础工程/任务基准，但不能替代上述专项能力验证。应分开回答：

1. 试验是否有效：失败是否可能来自坏输入、错误执行、标定、控制器或判据？
2. 模型是否有能力：在有效试验中，是否达到指定任务指标？
3. 优势来自什么：来自额外力/历史信息，还是同信息下四专家及路由架构？

**最新结论：还不能宣称“失败已排除所有其他原因”。** 已完成后述工程修复、示范回放与模型短测；未启动新训练、不热换统计、不改原数据、不把历史实验作废。下文保留原审计和逐次验证记录，以第10节最新验收状态为准。

### C05的数值证据（原审计）

当前统计中wrist2的state q01/q99为[-1.5709425211,-1.5701076782]，history为[-1.5709425211,-1.5704717636]。同一物理值-1.5707rad分别变为约-0.4190和0.03034，求差约-0.44935，tanh后约-0.42136。`_compute_expert_representation_loss`将该求差用于E1/E2目标。因此不是动作归一化文件错误，而是这个派生“运动量”的坐标尺度不一致。单独对不同输入归一化本身可以合法，直接把差解释为位移则不成立。

## 4. 专项能力：当前信息/训练/评估缺口

| 目标能力 | 已有基础 | 尚不能声称已具备的部分 |
|---|---|---|
| 密集接触 | FT当前/快慢窗口、E3/E4、成功装配示范 | 接触刚度/摩擦/侧向扰动分层评估；不能用抓取前失败概括接触能力 |
| 视野丢失 | E2历史编码、当前帧blackout/glare增广 | 连续故障历史、真实强光/局部遮挡、冻结图像、长时记忆及教师隔离尚未验收 |
| 安全接触 | 力信息与接触描述监督 | 感知力不等于优化安全；没有已验证的安全动作目标、统一力阈值/冲量指标和响应时延上界 |
| 力引导卡滞恢复 | 状态/FT历史可提供接触变化线索 | 当前50条完整成功轨迹中尚未建立按“卡滞事件→脱困→继续装配”标注验收的覆盖证明，不能因E3/E4命名就声称恢复技能已训练 |

100Hz FT窗口只是输入采样频率。当前预测50步、执行10步，约每1秒动作段之后才重推理，还需考虑计算/通信时间；不能称为100Hz力反馈控制。窗口里的接触变化不能在同一个已执行动作块内自动重写动作。安全反应能力若需更快刷新，应作为两模型共同执行合同设计，而不是只给PAP增加外部保护再归功于专家。

本轮不擅自增加恢复数据。先审计已有覆盖；覆盖不足就明确能力主张不足，不能靠增加同分布训练步数假装补齐。已有成功轨迹可能含接触调整，不等于已经具备系统卡滞恢复标注。

## 5. 如何证明特定情况优于基线

不是四种优势都必须同时做到。先选一个主目标，其余为探索性结果；在看结果之前固定条件与指标，避免事后寻找某个胜出的子集。

### 必需的对照层次

- Pi0.5原始信息接口：用于回答增加物理信息和模块后的整体收益。
