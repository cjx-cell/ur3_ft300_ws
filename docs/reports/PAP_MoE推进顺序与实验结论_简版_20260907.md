## 1. 先建立Pi0.5基线，再评估旧版PAP-MoE

使用Workspace50的50条示范，按5个位置×3个随机种子进行闭环评估，预测50步、执行10步。

旧版融合方式：

```text
观测 → 四个物理专家 → 路由加权的物理特征 ─────────┐
视觉语言、状态、带噪动作 → 动作Transformer → 隐特征h
                                                 ↓
                               末端条件融合 → 输出投影 → Flow去噪生成动作
```

物理特征在动作Transformer之后加入。它是隐特征残差融合，不是四个专家独立输出关节纠偏动作。ForceVLA也使用类似的末端融合位置，但专家设计、路由和融合计算不同。

## 3. 这些实验得到了什么结论？

1. **开环改善没有稳定转化成闭环改善。** 直接四路Gate的开环误差低于参考Pi0.5，但成功数只有3/15；阶段4继续降低部分开环误差，也没有带来稳定成功率提升。
2. **逐动作步路由并非增加时间分辨率就自然更好。** 使用未来真实路由时前10步误差为0.012519，换成预测路由后为0.021074，暴露了预测与条件适配差距，但不能据此把全部失败归因于Forecaster。
3. **取消Forecaster、让单Gate直接预测50步，也没有单独解决闭环。** 只训练Gate为0/15；联合训练后开环误差下降、成功数变为2/15，仍未超过Pi0.5的7/15。0→2次成功不足以证明稳健优势。
4. **当前结果支持继续检查专家信息与动作融合，而不是宣布某种融合方式无效。** 受测旧PAP中最好为5/15；这些有限场景和种子的结果，不能证明PAP普遍不如Pi0.5，也不能证明条件前移必然更优。

## 4. 排查专家作用，尝试把融合位置前移

关闭或扰动物理条件后，部分指标反而改善，说明专家条件并未稳定转化成动作收益。但这不足以证明“末端融合就是失败原因”。当时也尝试过弱残差、限幅和夹爪路径隔离，带有保护主路径的倾向；这些不是整体模型优化的必要条件。

随后修改为：

```text
观测 → 四个物理专家 → 50步路由下的物理特征 ──┐
                         带噪动作、时间嵌入 ──┤
                                            ↓
                  输入条件融合 → 动作Transformer → 输出投影 → Flow去噪生成动作
```

**核心区别：旧版在动作Transformer算完后融合；新版在其计算之前融合，让内部各层处理带有物理信息的动作token。两者都是特征条件化动作生成，不是从“动作纠偏”变为“才有特征”。**

新版还增加了专家表征监督、视觉历史编码和E2蒸馏，因此不能把整轮变化视为单独修改融合位置。前移是待验证假设，不是已证明有效的改进。

## 5. 新版训练之后，检查E1与工程链路

发现E1表征含有部分可读出的信息、动作梯度也能传到专家，但信息进入模型后未稳定改善动作。随后对E1内部归一化、三分支汇合方式做单变量联合训练，没有获得一致、实质性的预期收益。

之后确认：**9月4日的新训练分支使用了错误的分位数统计来源**，把逐episode分位数的加权平均当作全数据分位数；同时发现采集与在线力滤波逻辑不一致。

因此，新版诊断可用于定位问题，但不能据此认定新版架构不行，也不能声称新版优于旧版。新框架仍缺少正确统计及一致输入处理下的可靠闭环验证。

## 最终结论

**已经得到的结论：** 旧版多轮开环改善没有稳定转化为闭环提升；路由预测与物理条件利用需要共同考虑，不能只看平均flow误差选模型。

**尚未得到的结论：** 末端融合导致失败、前移一定更优、四专家整体超过Pi0.5，都没有被现有实验充分证明。

**当前顺序：** 先修正统计与采集／推理输入一致性，再在固定数据和执行合同下验证新版；不以新增恢复数据替代本轮问题排查。
