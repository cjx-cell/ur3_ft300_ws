## 已启动的同状态诊断

来源：`artifacts/deployment_validation_20260909_s4_success_lineage/closed/results.json` 全部 16 条，不只选失败或成功。S4、B、GT、Pred 各使用自己的真实 rollout 输入。

在查看干预结果前，按几何阶段连续区间边界、首个闭爪状态及终止前 3 个动作块选点。阶段由 peg 抬升、peg/hole 横向距离定义，只用于检索；不把“对准插入区域”冒充真实接触。

三组仅改变动作 Transformer 输入的物理条件：

1. native：当前专家特征与当前预测路由。
2. no_physics：融合强度设为 0，完整 Action Flow 仍执行；保留 Gate、视觉前缀和其他计算。
3. stale_features：使用上一真实观测的同身份四专家特征，当前路由不变。首块无真实历史，因此不执行该对照。

固定同一原始输入、归一化、噪声、视觉历史、原记录 RTC 尾块；完整生成 50 步。先要求 native 与自己的原记录最大差 < 1e-5 rad、路由差 < 1e-6；干预路由必须与 native 完全一致；旁路的实际融合范数必须为 0。不满足则停止，不把工程误差当模型结论。

stale_features 同时替换专家表征中融合的视觉/状态/力信息，不能单独证明 FT 有效，也不是信息完全消除。no_physics 可能形成训练分布外输入，其结果只代表该检查点的条件路径依赖性。
